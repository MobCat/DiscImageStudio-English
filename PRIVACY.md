# Disc Image Studio Privacy Policy

Effective date: 21 August 2026

Disc Image Studio is an optical disc image generator that runs entirely locally on Windows devices.

## Data handling

- The app reads only the images, folders, ISO files or raw audio track files the user explicitly selects.
- The app creates ISO, RAW, PNG, BIN and JSON files only in locations the user specifies.
- The app contains no network communication, does not upload user files, and does not collect telemetry, advertising identifiers, location, contacts, account information or any other personal information.
- The app uses no third-party analytics, advertising or cloud storage services.

Users can delete files the app created at any time through Windows File Explorer. Uninstalling the app does not automatically delete output files the user deliberately saved to the Documents folder or anywhere else.

If a future version adds networking, accounts, telemetry or other data processing, this policy will be updated before that version is released, and user consent will be obtained where applicable.
